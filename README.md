# Implementación de herramientas computacionales mediante Python para la enseñanza de ecuaciones diferenciales

Este repositorio contiene los códigos y materiales desarrollados para el proyecto de titulación: Implementación de herramientas computacionales mediante Python para la enseñanza de ecuaciones diferenciales. Los recursos estan desarrollados en Python y están destinados a ser utilizados como apoyo en la enseñanza de ecuaciones diferenciales.
